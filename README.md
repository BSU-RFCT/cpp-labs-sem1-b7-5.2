# Лабораторная 5.2 по C++ — семестр 1, вариант Б7

Сравнение алгоритмов сортировки: **пузырьковая** vs **быстрая**.

## Что делает программа

Запрашивает размер массива, заполняет два одинаковых массива случайными числами и сортирует каждый своим алгоритмом. По окончании выводит статистику: число сравнений и перестановок для каждого метода.

## Структура

| Файл | Содержимое |
|---|---|
| `sorts.h` / `sorts.cpp` | Реализации `bubbleSort` и `quickSort` (шаблонные) |
| `fill.h` / `fill.cpp` | Заполнение массива случайными значениями |
| `io.h` / `io.cpp` | Ввод/вывод, инициализация консоли |
| `stats.h` | Структура `Stats` для подсчёта операций |
| `profiler.h` | Инструмент замера времени |
| `main.cpp` | Точка входа |
